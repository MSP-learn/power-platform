# Contributor guides

This directory contains authoring guidance for people and agents maintaining the documentation source. MSP Portal does not publish these files because `.docs-source.yml` points only to `docs/`.

## Start here

- [Add a documentation page](authoring/README.md)
- [Review content before publication](reference/content-review-gateway.md)
- [Choose reader-centered Markdown patterns](reference/reader-experience-patterns.md)
- [Configure source metadata](reference/README.md)

Use these references to shape a deliverable without turning the published directory into a taxonomy of placeholder folders:

- [Architecture](architecture/README.md)
- [Concepts](concepts/README.md)
- [Workflows](workflows/README.md)
- [Patterns](patterns/README.md)
- [Components](components/README.md)
- [Examples](examples/README.md)
- [Snippets](snippets/README.md)
- [Troubleshooting](troubleshooting/README.md)

Reader-facing Markdown and its required assets belong directly under `docs/`. Keep this directory for reusable author guidance that should remain outside the MSP reading experience.
